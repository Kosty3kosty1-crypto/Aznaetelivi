# Ежедневный пост «А знаете ли вы?» в Telegram

Репозиторий публикует один пост в день в ваш Telegram-канал через GitHub Actions
(бесплатно, полностью автоматически, без необходимости держать компьютер включённым).

## Что внутри
- `facts.py` — банк из 63 фактов (хватит на ~2 месяца без повторов, дальше список
  начинает повторяться по кругу). У каждого факта указана статья в английской Википедии,
  откуда берётся тематическая картинка. Можно дописывать новые факты в конец списка
  в любой момент.
- `post.py` — скрипт, который выбирает факт дня, ищет для него картинку через бесплатный
  публичный API Wikipedia (без ключей) и публикует пост с фото в канал. Если подходящей
  картинки не нашлось — публикует обычный текстовый пост, чтобы день без фото не срывал публикацию.
- `.github/workflows/daily-post.yml` — расписание: каждый день в 09:00 по Москве.

## Настройка (5 минут)

1. Создайте новый **приватный** репозиторий на GitHub и загрузите туда все файлы
   из этой папки (сохранив структуру, включая папку `.github/workflows`).
2. В репозитории откройте **Settings → Secrets and variables → Actions → New repository secret**
   и добавьте два секрета:
   - `TELEGRAM_BOT_TOKEN` — токен вашего бота от @BotFather
   - `TELEGRAM_CHANNEL` — `@questionsforlive`
3. Убедитесь, что бот добавлен в канал **администратором** с правом публикации постов.
4. Готово. Workflow запустится автоматически каждый день в 09:00 по Москве.
   Проверить/запустить вручную можно во вкладке **Actions → Daily Telegram Fact Post → Run workflow**.

## Важно
- Секреты (токен бота) нужно ввести самостоятельно — я намеренно не могу и не должен
  вводить токены и пароли за вас.
- Скрипт сам ведёт `log.txt` и коммитит его после каждой публикации — это не даёт GitHub
  автоматически отключить расписание из-за "неактивности" репозитория (правило GitHub:
  scheduled workflows отключаются после 60 дней без коммитов).
- Когда факты в `facts.py` закончатся, я могу дописать ещё — просто попросите.
